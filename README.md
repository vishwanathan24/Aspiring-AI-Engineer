# TechPanda Student Sentiment Analysis

AI-powered student audio sentiment and emotion analysis system.

## Pipeline

Audio
↓
Audio preprocessing
↓
Whisper transcription
↓
Speaker identification
↓
Student extraction
↓
Sentiment analysis
↓
Emotion analysis
↓
Report generation

## Technologies

- Python
- Faster-Whisper
- Hugging Face Transformers
- PyTorch
- FFmpeg
- NumPy
- Pandas

## Supported Audio

- MP3
- WAV
- M4A
- FLAC
- OGG
- AAC
